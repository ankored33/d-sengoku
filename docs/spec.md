# d-sengoku 仕様書（ドラフト v0.3）

## コンセプト

**「国を富ませ、人を育てよ。天下は家臣が獲ってくる。」**

- 戦争は起きる。ただしプレイヤーは指揮しない。
- プレイヤーが行うのは **内政** と **人材育成** と **任命（軍大将・外交担当）** だけ。
- 戦の勝敗は「プレイヤーが用意したもの」で決まる。
  - 内政の成果 → 兵数・兵糧・鉄砲・城の防御
  - 人材の成果 → 軍大将の能力・家臣の忠誠・層の厚さ

### 中核のアイデア: 命令は家臣に任せる

内政の命令は、必ず家臣を1人選んで実行させる。

- 命令の効果は、担当した家臣の能力で決まる
- 担当した家臣には経験が入って成長する
- → **内政命令を出すこと自体が、そのまま人材育成になる**
- 毎月の悩みどころ: 「有能な者に任せて成果を取るか、若手に任せて育てるか」

## 決定事項

| 項目 | 決定 |
|---|---|
| 戦争への関与 | 軍大将の任命のみ。出陣・攻撃目標・合戦は家臣が自律判断 |
| 外交 | 担当者・相手の大名・目的を決めたら、あとは担当者が自動で進める |
| 武将 | 全員史実武将。能力値は独自に設定する |
| 時間 | 月ターン（12ターン/年） |
| マップ | 令制国の中に複数の城。本番は100〜200城 |
| 試作版（MVP） | 東海〜近畿の約40城。1560年5月（桶狭間）開始。大名家は選択制 |
| プラットフォーム | ブラウザ（HTML/JS） |
| 開発方針 | ゲームシステムを優先する。城・武将のデータは仮置きでよい |

## ゲームループ（1か月）

1. **報告** — 先月の戦果・事件・家臣の動向を読む
2. **評定** — 家臣に内政・外交・育成の仕事を割り振る。人事を行う
3. **進行** — 月末処理（命令の実行、城主の自動内政、軍大将の行動、合戦、収入、成長、忠誠、イベント）

## 1. マップ

- 城がノード、街道がエッジのグラフ。
- 令制国（尾張・美濃など）が複数の城を束ねる。国は表示・収穫・イベントの単位になる。
- 1つの国の城を全部押さえると「国主」になり、ボーナスがつく（案: 民忠↑、名声↑）。
- 城のパラメータ: 石高 / 商業 / 民忠 / 城防御 / 治水 / 兵数 / 城主
- 城の格: 本城・支城。支城は内政の上限が低い。

## 2. 内政

### 命令の出し方
- 家臣は **所属する城** を持つ。命令は、その城に所属する家臣にだけ出せる。
- 1人の家臣が引き受けられる命令は1か月に1件。
- 家臣を別の城へ移すには「移動」命令が必要（1か月かかる）。
- → 有能な家臣の数と配置が、そのまま内政の手数になる。

### 命令一覧
| 命令 | 効果 | 効く能力 |
|---|---|---|
| 開墾 | 石高↑ | 政治 |
| 商業 | 商業↑ | 政治 |
| 治水 | 水害の発生率と被害↓ | 政治 |
| 普請 | 城防御↑ | 統率 |
| 施し | 民忠↑（米を消費） | 政治 |
| 徴兵 | 兵数↑（民忠↓） | 統率 |
| 訓練 | 兵の練度↑ | 統率・武勇 |
| 調達 | 鉄砲・軍馬を購入（金を消費） | 知略 |
| 検地 | 石高↑、民忠↓（一揆のリスク） | 政治 |

- 効果 = 基本値 × 担当者の能力補正
- 担当者には、効いた能力の経験が入る。

### 城主の自動内政
- 命令が出なかった城では、月末に城主が自分で1件だけ内政を行う。
- プレイヤーは城主に **方針** を与える: 開発重視／軍備重視／民政重視／おまかせ
- 効果は城主の能力で決まる。
- → 城が100以上あっても、全部を手で回す必要はない。

### 収入
- 金: 毎月（商業から）
- 米: 秋に一括（石高から）
- 直轄収入 = 全体の収入 −（家臣の知行の合計に相当する分）
- 兵糧: 出陣中の軍勢は米を消費する。尽きると撤退する。

## 3. 人材

### 武将パラメータ
| 項目 | 内容 |
|---|---|
| 能力 | 統率 / 武勇 / 知略 / 政治（各 1〜100） |
| 潜在値 | 各能力の上限（史実の力量）。育成しても潜在値は超えない。プレイヤーにはランク（S/A/B/C/D）でだけ見せる |
| 経験 | 能力ごとに溜まる。100溜まると現在値が+1 |
| 忠誠 | 0〜100 |
| 知行 | 家臣に与えた石高。与えた分だけ当主の直轄収入が減る（知行制） |
| 年齢・寿命 | 史実の生年・没年がベース |
| 性格 | 勇猛・慎重・野心・義理 など。軍大将や外交担当の判断、忠誠の変動に効く |
| 出自 | 一門／譜代／外様／新参。忠誠の基本値が変わる |

### 役職
| 役職 | 仕事 |
|---|---|
| 一般 | 所属する城で内政命令を受ける。軍大将の配下として出陣する |
| 城主 | 1つの城を預かる。命令が出ない月は方針に沿って自動で内政する |
| 軍大将（いくさだいしょう・仮称） | 複数の城主を束ねる。束ねた城の兵を率いて、自分の判断で戦をする |

- 軍大将が束ねる城と家臣のまとまりは「〇〇勢」と呼ぶ（例: 柴田勢）。

### 身分（案）
- 称号の段階は作らない。与えた知行の石高が、そのまま家中での格になる。
- 知行の石高によって、就ける役職が決まる。

| 知行 | 就ける役職 |
|---|---|
| 〜千石 | 一般 |
| 千石〜 | 城主 |
| 一万石〜 | 軍大将 |

- 引き上げたい者には加増が必要になる。加増するほど直轄収入が減る。

### 成長
- 経験の入り方には年齢補正がかかる。

| 年齢 | 補正 |
|---|---|
| 〜20歳 | ×2.0 |
| 21〜30歳 | ×1.5 |
| 31〜45歳 | ×1.0 |
| 46〜55歳 | ×0.5 |
| 56歳〜 | ×0.2（武勇は毎年少しずつ下がる） |

- → 若手を早く使うほど伸びる。老将は即戦力だが伸びない。

### 経験が入る手段
| 手段 | 伸びる能力 | 備考 |
|---|---|---|
| 内政命令を担当する | 命令ごとに異なる | 育成の基本 |
| 城主を務める | 政治・統率 | 毎月少し |
| 軍大将・配下として出陣する | 統率・武勇 | 合戦ごとに多め。討死のリスクあり |
| 外交を担当する | 知略・政治 | |
| 師事する | 師匠の得意な能力 | 弟子は修行中は他の仕事ができない。師匠は普段どおり働ける |
| 学問・茶の湯 | 知略・政治 | 金を消費。忠誠も上がる |

### 忠誠
- 毎月、次の要素で変動する:
  - 出自と性格（義理の者は安定、野心家は当主より有能だと下がりやすい）
  - 知行が働きに見合っているか（手柄を立てたのに報いないと下がる）
  - 家の勢い（勝ち続けると上がる、負け続けると下がる）
- 褒美:
  - 金 — 小さく上がる
  - 知行の加増 — 大きく上がる。ただし直轄の収入が減る
  - 城主・軍大将への任命 — 上がる
- 忠誠が低いと:
  - 30未満: 出奔の危険
  - 20未満の城主・軍大将: 謀反（城ごと寝返る、または独立する）

### 登用・世代交代
- 史実の元服年になると、一門・家臣の子が登場する（若く、潜在値の高い者もいる）。
- 史実の登場年を過ぎた浪人を登用する。他家の武将を引き抜く（外交担当の仕事）。
- 寿命で死亡する。当主が死ぬと後継者が家督を継ぎ、家臣の忠誠が揺らぐ。

## 4. 軍大将と戦争（自動）

### プレイヤーがすること
- 軍大将を任命し、束ねる **城主** と **配下の家臣** を割り当てる
- 束ねた城の兵が、その軍大将の兵力（〇〇勢）になる。
- 攻撃目標・出陣の時期・兵数の指示は **一切できない**。

### 軍大将の判断（毎月）
1. 束ねる城に隣接する敵の城を候補にする（同盟国は除く）
2. 候補ごとに「予想勝率 × 城の価値」を評価する
3. 性格ごとのしきい値を超えれば出陣する
   - 勇猛: 予想勝率50%以上 ／ 普通: 65%以上 ／ 慎重: 80%以上
4. 兵糧・兵数が足りなければ出陣しない

### 合戦
- 野戦（敵が迎撃してきた場合）→ 攻城（数か月かかり、城防御が削れていく）
- 戦力 = 兵数 × 統率補正 × 武勇補正 × 練度 × 士気 × 鉄砲補正
- 結果はテキストで報告する（「柴田勝家、稲葉山城を攻略」など）。

### 防衛
- 軍大将に束ねられていない城は防衛のみ行う。隣接する自軍の城から援軍が出る。

### 手柄
- 勝つと、軍大将と配下の経験・名声が上がる。
- 功績の大きい者に知行で報いないと、忠誠が下がる（→ 野心家は独立の危険）。

## 5. 外交（自動）

- プレイヤーは **担当者** と **相手の大名** と **目的** を決める。あとは担当者が何か月もかけて自動で交渉する。
- 目的の例: 友好を深める／同盟／婚姻同盟／停戦／臣従を迫る／援軍要請／引き抜き
- 成否と所要期間は、担当者の知略・政治、相手との関係値、両家の国力差、相手当主の性格で決まる。
- 途中経過は報告される（「交渉は難航」「先方が前向き」など）。担当者を途中で差し替えることもできる。
- 外交の成果が軍大将の判断に影響する。例: 同盟国は攻撃目標にしない、援軍が来る。
- 担当中の家臣は他の仕事ができない（人材を配分する判断が生まれる）。

## 6. 勝敗

- **勝利**: 全城を支配（天下統一）
- **敗北**: 全城を喪失／当主死亡時に後継者がいない
- **実質的な時間制限**: 史実武将には生没年があるので、時代が進むと人材が尽きていく。
